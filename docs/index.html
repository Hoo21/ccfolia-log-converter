1. 원본 로그 불러오기

전체 로그원본이름[all].html 파일 1개를 끌어 놓거나 클릭해서 선택하세요.
모든 탭을 원래 순서대로 합친 전체 결과가 추가로 만들어집니다.
개별 탭 로그원본이름[main].html 등 탭별 파일을 끌어 놓거나 클릭해서 선택하세요.
여러 개를 한 번에 넣을 수 있습니다.

로그 모드 탭(main·other)에 나오는 캐릭터입니다. 역할을 나레이터로 정하면 가운데 정렬 지문으로, 제외로 정하면 출력하지 않습니다.

색 상자를 눌러 고르거나 #6자리 색상 코드(예: #1e1f21)를 입력하세요. 기본값과 다른 항목만 출력 CSS에 추가됩니다.

원본 로그에서 실수로 보이는 부분입니다. 공백 차이와 빈 메시지는 이미 자동으로 정리되었습니다.

    로그 중간에 넣을 큰 이미지입니다. 이미지를 블로그나 이미지 호스팅에 먼저 올린 뒤 주소를 넣으세요.
    코드를 복사해서 백업 파일의 원하는 줄 아래에 새 줄로 붙여 넣으세요. 블로그 HTML 편집 화면에서 Ctrl+F로 앞 대사를 검색하면 위치를 찾기 쉽습니다.

    결과 미리보기에서 나레이션을 클릭하면 그 위·아래에 컷씬을 넣을 수 있습니다. 넣은 컷씬은 다운로드·복사하는 출력 파일에 자동으로 들어갑니다.

    컷씬은 화면에 가까워질 때 불러옵니다.

    복사: 컷씬이 하나라도 등록되어 있으면 출력 파일에 컷씬 CSS(약 0.6 KB)가 들어갑니다. 컷씬은 우클릭·끌기·드래그 선택이 되지 않습니다.
    단독 복사: v1.7.5 이전 백업 파일이나 이미 올린 글에 붙일 때. 스타일이 코드 안에 들어가서 조금 깁니다.
    컷씬 위아래 여백은 출력 옵션 → 여백 · 글자 크기에서 정합니다. (기본: 항목 위아래 여백과 같음)

    출력 파일의 기본 디자인입니다. 프로필 이미지 칸·캐릭터 색·이미지 규칙은 변환할 때 출력 옵션에 맞춰 자동으로 뒤에 붙습니다.

    2. 결과

    이 탭의 처리 방식
    전체 결과에 포함할 탭
    각 탭의 표시 방식(로그·카드)과 카드 설정(자물쇠·▶·포함할 이름·카드별 포함)은 해당 탭 화면의 설정을 따릅니다. other는 카드 모양으로 들어갑니다.
    이 탭의 카드 표시

    카드를 복사해서 main 백업 파일의 원하는 줄 아래에 새 줄로 붙여 넣으세요. 백업 파일은 한 줄이 항목 하나입니다.
    이름 옆 ▶를 클릭하여 이름별 표시 상태를 설정할 수 있습니다. 회색으로 off 처리 됩니다. (기본 값: on)

    이 탭에서 포함할 이름
    이 탭은 출력하지 않습니다.

    이미지 연결 다른 캐릭터와 같은 이미지를 사용합니다.

    가명 대사는 원래 이름·이름 색 그대로 출력되고, 프로필 이미지만 연동 캐릭터의 것을 사용합니다.
    색마다 연동 캐릭터를 정하세요. 같은 색을 쓰는 캐릭터가 여러 명이면 결과 미리보기에서 구간으로 나눠 지정합니다.

    색대사 수연동 캐릭터
    맨 위 폴더(기본)의 첫 번째 이미지가 기본 이미지입니다. 표정은 결과 미리보기에서 대사를 클릭해 바꿉니다.
    얼굴 가운데를 클릭하면 위치가 자동으로 맞춰집니다.
    미리보기 칸을 끌어서 조정할 수 있습니다.
